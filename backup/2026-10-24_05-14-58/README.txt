KingdomBot - бот для Kingdom: Classic (Steam 368230)
=====================================================

Автономный бот, который играет за короля в Kingdom: Classic.
Управляет только королём (A/D/Shift/S), NPC - под управлением ИИ игры.
Бот читает состояние игры из kcdbg.txt (логгер KCLog5.dll, вклеенный в Assembly-CSharp.dll).

Игра пропатчена для управления скоростью: бот пишет скорость в speed.txt,
игра читает его каждую секунду и меняет Time.timeScale.
Игра запускается в окне, не захватывает фокус.

=====================================================
ЗАПУСК
=====================================================

Бот на текущей игре:
  cd C:\Users\joker\CodeProjects\Python\KingdomBot
  py bot3.py --own-focus --speed 4 --skip-tutorial --generation 1

  Параметры:
    --own-focus      бот сам забирает фокус окна игры
    --speed 4        скорость симуляции (1, 2, 4, 8)
    --skip-tutorial  автоскип обучения (зажать S на 5 сек)
    --generation 1   номер поколения (для эволюции)
    --dry            только решения, без нажатий клавиш
    --once           одно решение и выход
    --genome file    путь к файлу генома

Эволюция:
  py evo.py --pop 12 --rounds 10 --episode 30 --episode-increment 10 --speed 8 --restart

  Параметры:
    --pop 12              размер популяции (количество ботов в поколении)
    --rounds 10           количество поколений
    --episode 30          базовое время жизни бота в секундах
    --episode-increment 10  увеличение времени жизни за поколение (30 + 10 * N)
    --top-percent 0.25    процент лучших ботов для отбора (по умолчанию 25%)
    --speed 8             скорость игры (1x, 2x, 4x, 8x)
    --restart             перезапускать игру перед каждым ботом
    --no-restart          не перезапускать игру
    --baseline            сделать baseline из текущей сохранёнки и выйти
  --resetAll            сбросить всё обучение (удалить геном, историю, baseline, логи)
    --genome file         стартовый геном

Базовый запуск (без параметров):
  py bot3.py
  py evo.py

=====================================================
НАСТРОЙКА НАГРАД (bounties.txt)
=====================================================

Все награды и штрафы хранятся в bounties.txt. Бот и эволюция читают их при запуске.
Откройте файл, измените значения, сохраните, перезапустите бота.

Основные награды:
  coin_collect = 5.0        Сбор монеты с земли
  coin_spend = 4.0          Трата монеты на покупку
  buy = 2.0                 Покупка объекта
  buy_castle_base = 100.0    Первая база (Castle0)
  buy_castle_upgrade = 50.0 Апгрейд базы (Castle1+)
  buy_hammer = 10.0         Молоток -> Worker
  buy_bow = 15.0            Лук -> Archer
  buy_scythe = 5.0          Коса -> Farmer
  recruit_beggar = 20.0     Найм бомжа
  building = 10.0           Строительство здания
  tree_chop = 5.0           Рубка дерева (с рабочими)
  tree_chop_no_workers = -0.5  Попытка рубки без рабочих
  survival = 0.05            Выживание (за секунду)
  movement_walk = 0.05       Ходьба (за единицу дистанции)
  movement_run = 0.1        Бег (за единицу дистанции)

Штрафы:
  crown_lost = -1000.0        Потеря короны
  death = -10000.0           Смерть
  full_spend_penalty = -5.0 Полный расход без окупаемости
  idle = -40.0              Бездействие (за 5 сек)
  no_interaction = -15.0    Отсутствие взаимодействия
  horse_exhaustion = -5.0   Переутомление лошади
  coin_lost_enemy = -10.0   Потеря монеты от врага
  failed_* = 1/4 от стоимости  Неудачная попытка

Коэффициенты:
  failure_penalty_ratio = 0.5   Коэффициент штрафа за неудачу
  inactivity_progression = 1.1   Прогрессия штрафа за бездействие
  horse_rest = 6.0              Бонус за отдых лошади
  horse_rest_threshold = 0.5    Порог стамины для отдыха
  defense_day_bonus = 0.05      Бонус обороны по дням
  profession_missing_bonus = 5.0  Бонус за отсутствие профессии
  free_citizen_tool_bonus = 5.0  Бонус инструментов за свободных граждан
  free_citizen_bonus_* = 0-5.0  Бонусы предметов за свободных граждан

Градиент не подобранных монет:
  unpicked_coin = 1.0           Базовый множитель
  unpicked_coin_max = 5.0       Макс. штраф за монету (при 1 монете)
  unpicked_coin_min = 1.0       Мин. штраф за монету (при 30+ монетах)
  unpicked_coin_threshold = 30.0  Порог достижения минимума

=====================================================
МЕХАНИКА БОТА
=====================================================

Приоритеты покупок (по убыванию важности):
  1. Каменщик (mason)
  2. Замок/база (castle)
  3. Мастерская (workshop)
  4. Апгрейд стен (wall3, wall2, wall1)
  5. Новые стены (wall0)
  6. Башни (tower)
  7. Фермы (farmhouse)
  8. Статуи (statue)
  9. Границы/рыцари (border)
  10. Кони (steed)
  11. Торговцы (merchant)
  12. Деревья (tree)

Бонусы за свободных граждан (только для снаряжения):
  Инструменты (молоток/лук/коса): +5
  Граница (рыцарь): +2
  Остальные: 0

Бонус за отсутствие профессии:
  Если рабочих 0 -> молоток получает +5
  Если лучников 0 -> лук получает +5
  Если фермеров 0 -> коса получает +5

Бонус обороны по дням:
  С каждым днём приоритет обороны растёт на defense_day_bonus * день
  Ограничение: не превышает profession_missing_bonus - 0.1
