# KCbot — эволюционный бот для Kingdom: Classic

Бот для **Windows** и **Kingdom: Classic** (Steam 368230). Управляет
только королём (A/D, Shift, S), читает состояние игры через
пропатченный логгер и обучает стратегию эволюцией: **CEM + Pareto**,
с сохранённым старым **GA**-режимом.

**Релиз v1.0.3:**
https://github.com/rokki-j-walker/KCbot/releases/tag/v1.0.3

---

## Возможности

### Лаунчер
- Fluent-интерфейс на CustomTkinter, **9 тем** и **RU / EN**.
- Новая Fluent-иконка: тёмный квадрат, золотая корона, зелёный акцент.
- Масштаб окна: **Авто / 100% / 110% / 125%** (список слева от языка).
- **Главное окно фиксированного размера**; ресайз — только у консоли,
  справка тоже фиксирована.
- Компактная строка пути: значки «папка», «автопоиск», «патч/откат».
- **Кнопка «Обновить»**: проверяет GitHub Releases, скачивает установщик
  новой версии и запускает его (с проверкой SHA256).
- Патчер `Assembly-CSharp.dll` с бэкапом и откатом.
- «Детали»: итоговое время, количество поколений/ботов и расчёт по
  раундам без дублирования параметров.

### Бот
- Управление королём через Win32 `SendInput`; фокус удерживается,
  при потере фокуса бот **спит**, метрики и таймер стоят, через 5 минут
  фокус возвращается автоматически.
- **F8** — пауза: игра ставится на паузу через ESC; продолжение —
  фокус → ESC → бот.
- Детект проигрыша: бот сразу завершает эпизод, evo запускает нового.
- Экономический bootstrap: первая база и инструменты покупаются раньше
  найма; награды за рабочих, лучников и постройки сбалансированы.

### Обучение
- **CEM** (адаптивный поиск) по умолчанию, **GA** сохранён и выбирается
  в лаунчере.
- **Pareto-отбор**: выживание жёстко первым, затем очки и экономика.
- **1–3 оценки на геном** (2 — баланс шума и времени).
- Тёплый старт от `data/best_genome.json`; сохраняется лучший геном за
  весь прогон.
- История, геномы и подробные логи — в `data/` и `logs/` (runtime,
  не коммитятся).

## Установка

### Инсталлер
Скачать `KCbot-1.0.3.exe` из
[Releases](https://github.com/rokki-j-walker/KCbot/releases/tag/v1.0.3)
и запустить. Установка в пользовательский каталог, Python не нужен.

### Портативная версия
Скачать `KCbot-1.0.3-portable.zip`, распаковать в любую папку и запустить
`KCbot.exe`.

**Требования:** Windows 10/11 x64, установленная **Kingdom: Classic**
(Steam). Игра в комплект не входит.

### Первый запуск
1. Указать папку игры (или нажать «Автопоиск»).
2. Проверить/применить патч игры — без него логгер не пишет `kcdbg.txt`.
3. Выбрать алгоритм, число оценок и параметры прогона.
4. Нажать **Старт**; консоль и «Детали» покажут прогресс.

## Как это работает

1. **KCLog5** внутри `Assembly-CSharp.dll` пишет состояние игры в
   `kcdbg.txt`: позиция короля, монеты, граждане, враги, постройки.
2. `bot3.py` читает последнюю строку, принимает решение и отправляет
   клавиши в окно игры.
3. `evo.py` запускает эпизоды, считает фитнес по `bounties.txt` и
   обновляет популяцию геномов.
4. `data/best_genome.json` — лучший найденный набор из 31 параметра
   (приоритеты покупок, цели по юнитам, пороги движения).
5. `logs/` — подробные логи ботов и история прогонов.

## Параметры обучения

| Параметр | Смысл |
|---|---|
| Популяция | Ботов в одном поколении |
| Раунды | Поколений обучения |
| Эпизод, сек | Длительность одного эпизода при 1x |
| Прирост, сек | На сколько растёт эпизод каждый раунд |
| Скорость | 1x / 2x / 3x (4x+ ломает игру) |
| Топ | Доля лучших для отбора |
| Алгоритм | CEM (адаптивный) / GA (классический) |
| Оценок на геном | 1 / 2 / 3 — меньше шума, но дольше |

Время в «Деталях» пересчитывается с учётом популяции, раундов, эпизодов
и числа оценок. **`episode` задано в игровых секундах**: реальное время
прогона = игровые ÷ скорость, а перезапуск игры — реальные секунды и от
скорости не делится. Поэтому в «Деталях» **«Реальное время» зависит от
1x/2x/3x**, а **«Игровое время» одинаково при любой скорости**; обе цифры
обновляются при смене скорости.

## Сборка из исходников

```powershell
py -m pip install -r requirements.txt
py -m PyInstaller KCbot.spec --noconfirm --clean
& "C:\Program Files\utils\Inno Setup 7\ISCC.exe" KCbot.iss
Compress-Archive -Path 'dist\KCbot\*' -DestinationPath 'dist\KCbot-1.0.3-portable.zip' -CompressionLevel Optimal
```

Результаты:
- `dist/KCbot/KCbot.exe` — onedir-сборка (Windows x64);
- `Setup/KCbot-1.0.3.exe` — инсталлер Inno Setup 7;
- `dist/KCbot-1.0.3-portable.zip` — портативная версия.

Версия exe задаётся `KCbot_version.txt` (FileVersion 1.0.3.0).

### Проверка
```powershell
py -m pyflakes launcher.py
py scantest.py
py difftest.py check
py tracktest.py check
py exectest.py check
py paytest.py check
```

## Структура проекта

```
KCbot/
├── bot3.py              # бот: решения, ввод, метрики
├── evo.py               # CEM/GA, Pareto, эпизоды
├── bounties.txt         # награды и штрафы
├── launcher.py          # GUI-лаунчер
├── baseline.py          # baseline-сейв
├── human_trainer.py     # запись действий человека
├── patcher.py, dotnet.py# патч Assembly-CSharp.dll
├── gamepath.py, kc_common.py
├── restart.py, hold.py, shot.py
├── kcbot.py             # CLI
├── difftest.py, tracktest.py, exectest.py, paytest.py, scantest.py
├── locales/             # ru.json, en.json
├── assets/              # иконка, оформление
├── tools/               # KCLog5.dll + исходник
├── KCbot.spec           # PyInstaller
├── KCbot.iss            # Inno Setup
├── KCbot_version.txt    # версия exe
├── data/                # runtime: геном, история (не коммитится)
├── saves/               # baseline.dat (не коммитится)
└── logs/                # логи прогонов (не коммитится)
```
