# KCbot — бот для Kingdom: Classic

Автономный бот для игры **Kingdom: Classic** (Steam 368230). Играет за короля, управляя им (движение A/D, бег Shift, взаимодействие S). NPC остаются под управлением ИИ игры. Поведение бота эволюционирует: генетический алгоритм подбирает параметры стратегии, ориентируясь на внутриигровые события (сбор монет, строительство, выживание, защита короны).

## Цель

Максимизировать внутриигровой результат (coins, постройки, выживание, защита от врагов) за фиксированное время эпизода, подбирая параметры поведения короля эволюционным путём. Дополнительно поддерживается обучение на записях игры человека (ручной тренинг), результаты которого подмешиваются в популяцию.

## Как достигается цель

- **Сбор состояния игры.** В `Assembly-CSharp.dll` игры вклеен логгер `KCLog5.dll`, который пишет состояние (монеты, позиция, события) в `kcdbg.txt`. Бот читает этот файл.
- **Управление.** `bot3.py` отправляет нажатия клавиш в окно игры (A/D/Shift/S) через Win32 API. Игра запускается в окне и не захватывает фокус.
- **Скорость симуляции.** Игра пропатчена: бот пишет множитель в `speed.txt`, игра читает его и меняет `Time.timeScale` (1×–8×), что ускоряет эволюцию.
- **Эволюция.** `evo.py` запускает N ботов за эпизод, оценивает их по системе баллов (bounties) и отбирает лучших (элитизм + кроссовер + мутации). Результат сохраняется в `best_genome.json`, история — в `evo_history.json`.
- **Ручной тренинг.** `human_trainer.py` записывает действия игрока в нескольких сессиях, конвертирует их в геномы (`human_genome_N.json`). При включённой галочке «Подмешивать ручных ботов в эволюцию» они подмешиваются в популяцию (с мутациями со 2-го раунда).
- **Сброс.** `--resetAll` удаляет историю, лучший геном, baseline, логи и записи ручного обучения, пересоздаёт baseline из текущего сохранения.

## Структура

```
KCbot/
├── bot3.py              # одиночный запуск бота
├── evo.py               # эволюция (генетический алгоритм)
├── human_trainer.py     # ручное обучение на действиях игрока
├── converter.py         # конвертация записи → геном
├── hold.py, shot.py     # вспомогательные утилиты
├── gamepath.py          # определение папки игры (из настроек лаунчера)
├── CSharp/KCbotWpf/     # WPF-лаунчер (C# / .NET 8)
├── assets/              # иконки, инструменты патчинга
├── lang/                # ru.json, en.json
├── data/                # геномы, история, логи
├── saves/               # baseline.dat
└── tools/               # patch.exe, KCLog5.dll, Mono.Cecil.dll
```

## Лаунчер (C# WPF)

Графическая оболочка над Python-движком:

- запуск/остановка обучения, консоль вывода в реальном времени, график эволюции (ScottPlot);
- все параметры эволюции в UI (2 колонки) + расчёт ожидаемого времени;
- выбор папки игры + автопоиск (реестр Steam / библиотеки), определение и применение патча;
- ручное обучение: окно с длительностью записи (10–1800 с) и числом записей (1–50), скорость симуляции;
- сброс обучения с подтверждением;
- галочка «Подмешивать ручных ботов в эволюцию»;
- 7 тем (Fluent 2), RU/EN локализация, переключение на лету;
- тема-зависимые иконки, поиск по справке.

Путь к игре хранится в `%APPDATA%/KCbot/settings.json` (`game_dir`) и передаётся движку через `--game-dir`. Хардкода пути в коде нет.

## Требования

- Windows 10/11, .NET 8 Runtime (для лаунчера)
- Python 3.10+ с зависимостями (numpy и др.)
- Kingdom: Classic (Steam 368230), пропатченная для изменения скорости
- Steam-установка игры (путь определяется автоматически или указывается вручную)

## Запуск

Через лаунчер: `KCbotWpf.exe` → указать папку игры → «Старт».

Напрямую:
```
py bot3.py --own-focus --speed 4
py evo.py --pop 12 --rounds 10 --episode 30 --episode-increment 10 --speed 8 --restart
py human_trainer.py --sessions 4 --duration 120
py evo.py --resetAll --game-dir "C:\...\Kingdom"
```

Горячие клавиши в игре: **F8** — пауза/возобновление, **F9** — скриншот, **F12** — аварийная остановка (бот + игра + обучение).
