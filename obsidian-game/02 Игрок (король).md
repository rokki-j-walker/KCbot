# 02 Игрок (король)

## Управление
| Клавиша | Действие |
|---|---|
| A / D | идти влево / вправо |
| Shift | галоп (спринт), тратит стамину |
| S | контекстное действие: оплата (если выбран Payable) или бросок монеты |
| Esc | меню (пауза) |
| Enter | подтверждение / закрыть меню |

## Статы короля (из `kcdbg`)
- `px` — позиция по X (мир 2D, движение влево/вправо).
- `py` — позиция по Y (земля ≈ 0.88).
- `st` — стамина (0..1), при 0 лошадь выдыхается.
- `purse` — монеты в кошельке.
- `hc` — есть ли корона (1/0).
- `crown_x` — позиция упавшей короны.
- `as` — действие: `Stand`, `Walk`, `Run`, `Eat`, `Rear`.
- `sel` — выбранный Payable (под королём).
- `ps` — состояние оплаты: `None`, `Holding`, `Transaction`, `Completed`, `Cancelling`.

## Оплата
1. Подойти к объекту.
2. **Полностью остановиться** (круги появляются только в покое).
3. Дождаться появления кружков.
4. Нажать S (удерживать до завершения транзакции).
5. `purse` уменьшается на цену.

## Бросок монеты / найм
- Если `sel = None`, S бросает монету у ног короля.
- Бомж (B) подбирает монету → становится Peasant (P).
- Король может случайно подобрать свою же монету — этого нельзя допускать.

## Лошадь
- Спринт тратит стамину; при 0 — переутомление.
- Отдых восстанавливает стамину (стоя/шагом).
