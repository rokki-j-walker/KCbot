# 09 kcdbg — поля состояния

Формат строки: `KC|px=...,py=...|ps:None|as:Stand|...|day=0,time=...,playing=True,...|...`

## Игрок
| Поле | Смысл |
|---|---|
| `px`, `py` | позиция |
| `st` | стамина |
| `purse` | монеты |
| `hc` | корона (1/0) |
| `crown` | X упавшей короны |
| `sel` | выбранный Payable (`Тип,цена@x~Имя`) |
| `ps` | состояние оплаты |
| `as` | действие (Stand/Walk/Run/Eat/Rear) |

## Мир
| Поле | Смысл |
|---|---|
| `day`, `time` | день и время |
| `playing` | игра идёт |
| `next` | следующее событие |
| `dayT` | день |
| `safe` | безопасно |
| `cf` | ? (флаг) |
| `arc`,`wrk`,`frm`,`knt` | граждане |
| `wall`,`shop`,`farm`,`portal` | постройки |
| `camp`,`work` | лагерь/работы |
| `atk` | атакуют короля |
| `en`,`troll`,`ogre`,`squid` | враги |
| `gc` | монеты на земле (X) |
| `camps` | лагеря (X) |
| `ports` | порталы `x:free:?` |
| `stat` | статуи `Deity@x:charges` |
| `tow` | слоты башен + граждане |
| `cit` | граждане `TAG@x:coins` |
| `kng` | рыцари |
| `tool` | инструменты |
| `walls` | стены |
| `farms` | фермы |
| `shops` | магазины |
| `pay` | оплачиваемые объекты |
| `enm` | враги `Тип@x:atk` |

## Использование ботом
- `ReadState` читает последнюю строку `KC|` из хвоста файла.
- `StateParser.ParseLine` разбирает все секции.
- Метрики (`Bot.Track`) считаются по изменениям этих полей.
