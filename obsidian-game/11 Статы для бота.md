# 11 Статы для бота

## Что оптимизирует бот
| Метрика | Источник в игре | Вес (bounties) |
|---|---|---|
| `coins_in` | рост `purse` | +5/монета |
| `coins_spent` | падение `purse` | +4/монета |
| `buys` | успешные оплаты | +2 |
| `buildings_started/completed` | рост `wall+shop+farm` | +2/+10 |
| `recruited_beggars` | рост `P` | +20 |
| `first_archer/worker` | первый A/W | +15 |
| `trees_chopped` | уменьшение деревьев | +5 |
| `unpicked_coins` | `gc` | −1..−5/монета |
| `failed_*` | неудачные действия | штраф |
| `crown_lost` | `hc 1→0` | −1000 |
| `deaths` | game over | −3000 |
| `inactivity_penalty` | простой | −15/период |
| `survival` | время | +0.05/сек |

## Приоритеты поведения
1. Безопасность: убегать от врагов (`danger_dist`, `flee_dist`).
2. Экономика: собирать монеты, налоги, рубить деревья.
3. Развитие: нанимать бомжей (подтверждение по `P`), покупать инструменты.
4. Строительство: стены/замок (растёт приоритет обороны по дням).
5. Не простаивать: возвращаться к базе, искать монеты/деревья.

## Подтверждение действий
- Найм — только по появлению `P` после броска.
- Покупка — только если `spent >= price`.
- Оплата — стоять неподвижно 0.5 с, дождаться кружков.
