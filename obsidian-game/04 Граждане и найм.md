# 04 Граждане и найм

## Типы граждан (`kcdbg`)
| Тег | Тип | Роль |
|---|---|---|
| `B` | Бомж (Beggar) | подбирает брошенную монету → становится `P` |
| `P` | Крестьянин (Peasant) | свободный, можно дать инструмент |
| `W` | Рабочий (Worker) | рубит деревья, строит |
| `A` | Лучник (Archer) | защита |
| `F` | Фермер (Farmer) | доход |
| `K` | Рыцарь (Knight) | сильная защита |

## Найм (бросок монеты)
1. Найти бомжа `B` рядом (в радиусе ~3).
2. Убедиться, что `sel = None` (иначе S оплатит объект).
3. Нажать S — монета падает у ног короля.
4. **Отойти**, чтобы не подобрать монету самому.
5. Бомж подбирает → появляется `P` (Peasant).
6. Подтверждение: число `P` увеличилось.

## Инструменты
- `ToolHammer` → рабочий (W).
- `ToolBow` → лучник (A).
- `ToolScythe` → фермер (F).
- Покупаются в магазине (`PayableShop`), требуют свободного `P`.
