# 06 Враги и волны

## Источники врагов
- Порталы (`portal`, `ports` в `kcdbg`).
- Ночные волны (`Director` → `SpawnWave`).
- Типы: обычные (`Regular`), тролли (`troll`), огры (`ogre`), спруты (`squid`).

## Поля `kcdbg`
- `en` — число врагов.
- `troll`, `ogre`, `squid` — счётчики типов.
- `enm:` — список `Тип@x:атакует`.
- `atk` — атакует ли кто-то короля.
- `portal`, `ports` — порталы.

## Поведение
- Враги идут к королю/постройкам, атакуют.
- Король не умеет драться — только убегать.
- Ночью опасность выше; `safe=False`.

## Для бота
- Убегать при `danger_dist`, увеличивать `flee_dist`.
- Не стоять рядом с врагом.
- Спринт при побеге.
