## Ключевые классы игры
| Класс | Назначение |
|---|---|
| `Managers` | глобальные синглтоны: `kingdom`, `director`, `enemies`, `saves`, `tutorial`, `payables`, `stats`, `game` |
| `Game` | состояние игры, интро, меню, рестарт, выход |
| `Director` | время, день/ночь, волны |
| `Kingdom` | королевство: король, монеты, события |
| `Player` | король: движение, стамина, лошадь, действия |
| `PayableManager` | оплачиваемые объекты (деревья, стены, замок…) |
| `PersistentManager` | сохранения |
| `TutorialManager` | обучение |
| `EnemyManager` | враги и волны |
| `Stats` | статистика |
