# Kingdom: Classic — Obsidian Vault

База знаний по игре, собранная из декомпилированной `Assembly-CSharp.dll` (копия в `_game_analysis/`, оригинал не изменялся) и лога `kcdbg.txt`.

## Как открыть
1. Obsidian → «Open folder as vault» → папка `obsidian-game`.
2. Начните с `00 Индекс игры.md`.

## Состав
- `00` — индекс и классы
- `01` — цикл игры
- `02` — игрок (король)
- `03` — экономика
- `04` — граждане и найм
- `05` — постройки
- `06` — враги и волны
- `07` — день и ночь
- `08` — сохранения
- `09` — поля `kcdbg.txt`
- `10` — управление и меню
- `11` — статы для бота

## Правило ведения
При изменении логики бота сверяйтесь с этой базой, чтобы не потерять контекст игры. Обновляйте `11 Статы для бота` при изменении метрик.
