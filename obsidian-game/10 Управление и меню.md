# 10 Управление и меню

## Клавиши
| Клавиша | Действие |
|---|---|
| A / D | движение |
| Shift | галоп |
| S | действие (оплата/бросок монеты) |
| Esc | меню/пауза |
| Enter | подтвердить/закрыть меню |

## Меню (`Menu`)
- Кнопки: Continue, New Game, Options, Save + Quit, Quit, Credits.
- По умолчанию выбрана Continue (`SelectContinueButtonLater`).
- `Game.ShowMenu()` ставит `Time.timeScale = 0` (пауза).
- `Game.HideMenu()` ставит `Time.timeScale = 1`.

## Настройки при старте
- Иногда игра открывает окно настроек (считает частые перезапуски проблемой).
- Закрывается нажатием **Enter**, после чего игра продолжается.
