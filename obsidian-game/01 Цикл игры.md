# 01 Цикл игры

## Основной цикл
1. Игра загружает сохранение `AUTO` или начинает новую игру.
2. Идёт день (день/ночь цикл), король собирает монеты, нанимает людей, строит.
3. Ночью приходят волны врагов (порталы).
4. Цель — продержаться как можно дольше, построить замок, защитить корону.
5. Потеря короны → экран проигрыша (`The Crown Lost`).

## Состояния `Game`
- `gameState`: 0 — меню, 1 — интро, 2 — игра, 3 — game over.
- `menuState`: 0 — нет меню, 1 — меню, 2 — credits.
- `Game.StartGame()` — старт, `Game.Restart()` — новая игра (удаляет AUTO), `Game.Exit()` — выход.

## Интро и обучение
- `IntroSequence.RunSequence()`: `gameState=1`, `director.playing=false`.
- `_allowEndIntro` включается после `unresponsivePeriod` (или сразу при `tutorialCompleted=1`).
- Скип: удержание кнопки действия (S) дольше `skipButtonHoldDuration` → `Game.AbortIntroAndTutorial()`.
- Движение (A/D) → `IntroSequence.PlayerTriedToMove()` → `EndIntro()`.

## Game over
- `Game.StartGameOverSequence()` → `GameOverSequence()`.
- Признак в `kcdbg`: `playing=False`, `hc=0` (корона потеряна).
