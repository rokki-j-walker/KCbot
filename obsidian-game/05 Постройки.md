# 05 Постройки

## Типы Payable (`kcdbg` → `pay:`)
Формат: `Тип,цена@x~Имя(Clone)`.

| Объект | Тип | Цена | Назначение |
|---|---|---|---|
| `Tree` | `PayableTree` | 1 | рубка → монета |
| `Wall0` | `PayableUpgrade` | 1 | стена (базовая) |
| `Wall1..3` | `PayableUpgrade` | 1 | улучшение стены |
| `Tower0` | `PayableUpgrade` | 3 | башня |
| `Farmhouse0` | `PayableUpgrade` | 6 | ферма |
| `Castle0` | `PayableUpgrade` | 1 | замок (база) |
| `Castle1+` | `PayableUpgrade` | 3+ | улучшение замка |
| `Mason Shrine` | `PayableUpgrade` | 7 | святилище каменщика |
| `Statue Archer/Worker` | `Statue` | 5–6 | статуя (заряд) |
| `Merchant` | `Merchant` | 4 | торговец |
| `Steed` | `Steed` | 3 | лошадь |
| `Workshop` | `PayableWorkshop` | — | мастерская |
| `Border` | `PayableBorder` | — | граница (рыцари) |

## Строительство
- Требует рабочих (W) с молотками.
- `wall`, `shop`, `farm`, `portal` в `kcdbg` — счётчики построек.
- Улучшения замка: `Castle0` → `Castle1` → …
