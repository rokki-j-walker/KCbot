# 01 Обзор проекта

## Цель
Автономный бот для **Kingdom: Classic** (Steam 368230), который играет за короля и эволюционирует: генетический алгоритм подбирает параметры стратегии по внутриигровым очкам. Плюс WPF-лаунчер для управления обучением.

## Средства достижения
1. **Сбор состояния** — пропатченная игра пишет состояние в `Kingdom_Data/kcdbg.txt` (логгер `KCLog5.dll`).
2. **Управление** — бот отправляет клавиши (A/D/Shift/S) через Win32 `SendInput`.
3. **Скорость** — игра читает `speed.txt` и меняет `Time.timeScale` (1×–8×).
4. **Эволюция** — `evo.py` / `KCbotEngine` прогоняет популяцию ботов, считает очки и отбирает лучших (элитизм + кроссовер + мутации).
5. **Ручное обучение** — запись действий игрока → геномы → подмешивание в эволюцию.

## Компоненты
- **Python-движок** — оригинал: `bot3.py`, `evo.py`, `converter.py`, `recorder.py`, `human_trainer.py`, `restart.py`, `gamepath.py`.
- **C#-движок** — `CSharp/KCbotEngine` (порт Python-логики).
- **Лаунчер** — `CSharp/KCbotWpf` (WPF, .NET 8).
- **Тесты** — `CSharp/KCbotEngine.Tests` (xUnit, 21 тест).

## Требования
- Windows 10/11, .NET 8 Runtime
- Python 3.10+ (для Python-движка)
- Kingdom: Classic, пропатченная (KCDbg)
- Путь к игре хранится в `%APPDATA%/KCbot/settings.json` (`game_dir`)
