# 10 Задачи и известные проблемы

## Открытые задачи
- [ ] Улучшить подтверждение покупки: сейчас при росте кошелька во время оплаты (`spent < 0`) объект может ошибочно попасть в бан. Нужно определять успех по исчезновению/апгрейду объекта.
- [ ] Найм: повысить долю успешных (сейчас ~1 из 3) — точнее позиционировать бомжа и увеличивать окно проверки.
- [ ] Обучить бота проходить туториал (Day 0) быстрее.
- [ ] Уменьшить `unpicked_coins` (10 монет на земле) — приоритет сбора.
- [ ] Добавить тесты на `Bot.Decide`, `Bot.DoPay`, `Evo.ParseMetrics`, авто-очистку.
- [ ] Проверить поведение при 4×/8× (тайминги settle/recruit).
- [ ] Синхронизировать `bounties.txt` и C#-дефолты (сейчас C# читает файл, но дефолты — резервные).

## Известные ограничения
- `kcdbg.txt` содержит только X монет (без Y) → бот может гнаться за недостижимой монетой (есть таймаут/бан).
- Игра получает клавиши только в фокусе; `SetForegroundWindow` может блокироваться Windows, если пользователь активно работает.
- `evo_history.json` содержит старые выбросы (смерти до смягчения `death`), из-за чего график по Y растянут.
