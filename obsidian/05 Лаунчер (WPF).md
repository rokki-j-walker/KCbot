# 05 Лаунчер (WPF)

Проект: `CSharp/KCbotWpf` (WPF, .NET 8, MaterialDesign, ScottPlot 5).

## Окна
### MainWindow
- Параметры эволюции в 2 колонки, компактные поля.
- Кнопки «Папка игры», «Автопоиск» в шапке карточки.
- Действия: По умолчанию / Старт / Стоп / Ручное обучение / Сбросить обучение.
- Галочки: «Перезапускать игру между раундами», «Подмешивать ручных ботов в эволюцию».
- Тема (7 вариантов), язык RU/EN, справка, консоль, график.

### ConsoleWindow
- Виртуализированный `ListBox` (Recycling) — без лагов на 20 000+ строк.
- Пакетная вставка (очередь + таймер 50 мс).
- Кнопки: авто-прокрутка, очистить, копировать, сохранить, A−/A+.
- Поиск удалён (вызывал зависание).

### ChartWindow
- ScottPlot: средний скор, точки ботов, сглаживание, лучший, экспорт CSV.
- **Колесо** — масштаб X; **Ctrl+колесо** — масштаб Y; **ЛКМ-перетаскивание** — панорама X/Y.
- Яркая жирная линия нуля по Y; сетка Y ярче.
- Вид сохраняется при обновлении данных (сброс — кнопкой).

### ManualTrainWindow
- Длительность записи (10–1800 с), количество записей (1–50), скорость (1×/2×/4×, если игра пропатчена).

## Настройки (`%APPDATA%/KCbot/settings.json`)
`game_dir`, `python_dir`, `speed`, `use_human`, `manual_duration`, `manual_sessions`, `manual_speed`, параметры эволюции, `language`, `appearance_mode`.

## Запуск движка
`TrainingRunner` предпочитает `KCbotEngine.exe` (ищет в папке лаунчера, `PythonDir/CSharp/KCbotEngine/bin/...`), иначе — Python.
