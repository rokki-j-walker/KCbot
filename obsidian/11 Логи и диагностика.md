# 11 Логи и диагностика

## Где что лежит
| Что | Путь |
|---|---|
| Состояние игры | `Kingdom_Data/kcdbg.txt` (растёт, чистится >256 МБ) |
| Скорость | `Kingdom_Data/speed.txt` |
| Логи раундов | `logs/round<N>_bot<M>.log` |
| История | `data/evo_history.json` |
| Лучший геном | `data/best_genome.json` |
| Live-результат | `_tmp_live.json` |
| Результат эпизода | `_tmp_result.json` |
| Диагностика лаунчера | `%TEMP%/kcbot_runner.log` |

## Диагностика лаунчера
`TrainingRunner` пишет строку вида:
```
[HH:mm:ss] UseEngine=True File=...KCbotEngine.exe WorkDir=... Args=...
```
Позволяет увидеть, какой движок и с какими аргументами запущен.

## Частые проблемы
| Симптом | Причина | Решение |
|---|---|---|
| Бот «решает», но не двигается | `SendInput` не отправляет (размер `INPUT`) | проверить лог на `!! SendInput не сработал` |
| Кракозябры в консоли | движок пишет не в UTF-8 | `Console.OutputEncoding = UTF8` |
| `окно не найдено` | игра не запущена/не в фокусе | `--restart`, подождать окно |
| Бот завис | `kcdbg.txt` огромный | авто-очистка, tail-read |
| Консоль лагает | тысячи строк в RichTextBox | виртуализированный ListBox |
| `JsonElement` краш | результат бота читался как object | `Evo.ParseMetrics` |

## Полезные команды
```powershell
# размер kcdbg
(Get-Item "C:\...\Kingdom_Data\kcdbg.txt").Length/1GB
# процессы
Get-Process KCbotEngine,Kingdom,KCbotWpf
# лог лаунчера
Get-Content "$env:TEMP\kcbot_runner.log"
```
