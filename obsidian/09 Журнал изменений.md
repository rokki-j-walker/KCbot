- **Причина, почему обучение не стартовало и бот «не работал»**: игра хранит сейв в `%USERPROFILE%\AppData\LocalLow\noio\Kingdom\storage_v26_AUTO.dat`, а C#-движок копировал baseline в `%LOCALAPPDATA%\Low\noio\Kingdom\...` (`AppData\Local\Low` — другая папка). Игра никогда не видела baseline и всегда начинала новую игру (интро), где бот стоял.
- Исправлено во всех местах: `GameRestart`, `BaselineBuilder`, `Evo` (C#), `restart.py` (Python).
- Проверено: `baseline восстановлен: ...LocalLow...`, игра загружает сейв, бот играет (12 монет, Wall0 + Castle0, счёт 181).
- Baseline обновлён на корректный (после скипа обучения).

## 2026-11-04
- **Критический фикс `SendInput`**: в C# `INPUTUNION` не хватало 32-байтного padding → клавиши не отправлялись, бот «бездействовал». Добавлено `[StructLayout(Size=32)]` + предупреждение при ошибке.
- **Оплата**: ожидание реальной остановки (позиция ±0.05, 0.5 с), затем кружки, затем S.
- **Найм**: подтверждение по появлению `Peasant (P)`; отход от бомжа; своя монета в чёрном списке на 4 с; `recruited_beggars` только по факту.
- **Монеты**: стабильная цель (больше не дёргается между −14/−15/−16).
- **`kcdbg.txt`**: авто-очистка >256 МБ (Python и C#); чтение только хвоста 256 КБ.
- **`JsonElement`**: фикс краша при чтении результата бота.
- **UTF-8**: фикс кракозябр в консоли лаунчера.
- **Консоль**: виртуализированный список, без поиска.
- **График**: колесо = X, Ctrl+колесо = Y, ЛКМ = панорама X/Y, линия нуля, яркая сетка Y.
- **`Bot.Track`**: полный перенос метрик из Python (buildings_completed, trees_chopped, horse, crown, deaths, citizens-дельта, мировые события).
