# 12 Игра и сохранения (декомпиляция)

> Оригинальные файлы игры не изменялись. `Assembly-CSharp.dll` скопирован в `_game_analysis/` и разобран там (Mono.Cecil).

## Найденные классы
| Класс | Роль |
|---|---|
| `PersistentManager` | сохранения: `GetSavePath`, `Save`, `Load`, `SaveExists`, `DeleteSavedGame` |
| `Menu` | меню: `OnButtonNewGame`, `OnButtonNewGameConfirmed`, `OnButtonContinue`, `OnButtonSaveAndQuit` |
| `Game` | `StartGame`, `Restart`, `AbortIntroAndTutorial`, `Exit` |
| `IntroSequence` | интро: `PlayerTriedToMove`, `AbortIntro`, `EndIntro` |
| `TutorialManager` | туториал: `StartStep`, `CompleteTutorial` (`PlayerPrefs "tutorialCompleted"`) |

## Путь сохранения
`PersistentManager.GetSavePath(slot)` = `Path.Combine(Application.persistentDataPath, $"storage_v26_{slot}.dat")`.
Для Windows: **`%USERPROFILE%\AppData\LocalLow\noio\Kingdom\storage_v26_AUTO.dat`**.

> [!warning] Важно
> Раньше код копировал baseline в `%LOCALAPPDATA%\Low\noio\Kingdom\...` (это `AppData\Local\Low`, **другая** папка). Игра её не видела и всегда начинала новую игру. Исправлено на `AppData\LocalLow`.

Формат — `BinaryFormatter` от объекта `Storage`.

## Поток новой игры
1. Запуск игры: если `storage_v26_AUTO.dat` есть — загружается; если нет — автоматически начинается новая игра.
2. `Menu.OnButtonNewGameConfirmed` → `Game.Restart()`: `DeleteSavedGame("AUTO")`, `SceneManager.LoadScene("loader")`.
3. Интро (`gameState=1`): `TutorialManager.StartStep(0)`; `_allowEndIntro` включается после `unresponsivePeriod` (или сразу, если `tutorialCompleted=1`).
4. Скип обучения: **удерживать S ~3–4 с** → `Game.Update` видит `GetButton(1)` дольше `skipButtonHoldDuration` → `AbortIntroAndTutorial()`.
5. Если при старте открылось окно настроек (игра считает частые перезапуски проблемой) — **нажать Enter**, игра закроет его и продолжит.
6. Автосейв: `PersistentManager.HandleOnBecameSafe()` → `SaveDelayed()` при `safe` и `day > 0`.
7. `Menu.OnButtonSaveAndQuit()` → `Save("AUTO")` + `Application.Quit()`.

## Реализованный flow baseline
- Если `saves/baseline.dat` есть → копируется в `storage_v26_AUTO.dat` перед каждым эпизодом (`GameRestart.BaselinePath`).
- Если нет:
  1. лаунчер спрашивает подтверждение;
  2. `KCbotEngine --create-baseline` запускает игру (новая игра автоматически);
  3. ждёт окно, фокусирует, нажимает Enter (закрыть настройки), удерживает S 4 с (скип обучения);
  4. ждёт появления `storage_v26_AUTO.dat`;
  5. закрывает игру, копирует сейв в `saves/baseline.dat`;
  6. запускает обучение.

## Важно
- Если сейв загружен (не новая игра) — скипать обучение не нужно.
- Скип S выполняется только при `day == 0` (новая игра).
- `tutorialCompleted=1` уже стоит в `HKCU\Software\noio\Kingdom`.
