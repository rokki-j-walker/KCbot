# 14 Сборка и релиз

## Сборка
```bash
cd CSharp
dotnet build KCbotEngine/KCbotEngine.csproj
dotnet build KCbotWpf/KCbotWpf.csproj
```

## Тесты
```bash
cd CSharp
dotnet test KCbotEngine.Tests/KCbotEngine.Tests.csproj
```
21 тест (xUnit).

## Публикация (portable)
```bash
cd CSharp/KCbotWpf
dotnet publish -c Release -o publish
```

## Инсталлер (Inno Setup)
- Скрипт: `%TEMP%\kcbot.iss` (AppId, имя `KCbot_Setup_v0.0.4`, `OutputBaseFilename`).
- Компилятор: `C:\Program Files\utils\Inno Setup 7\ISCC.exe`.
- Установка в `{autopf}\KCbot`, ярлыки в меню Пуск/рабочий стол.

## Релиз на GitHub
```bash
git tag v0.0.4
git push origin master
git push origin v0.0.4
gh release create v0.0.4 KCbot_v0.0.4.zip --title "v0.0.4" --notes "..."
gh release upload v0.0.4 KCbot_Setup_v0.0.4.exe KCbot_v0.0.4_portable.exe
```

## Артефакты
- `KCbot_v0.0.4.zip` — полная публикация.
- `KCbot_Setup_v0.0.4.exe` — инсталлер.
- `KCbot_v0.0.4_portable.exe` — один exe.

## Важно
- `dotnet build` падает, если приложение запущено (файл занят) — сначала закрыть.
- `bin/`, `obj/`, `_game_analysis/` не коммитить.
