# 06 Метрики и скоринг

## Геном (параметры стратегии)
`keep_coins`, `low_gold_threshold`, `tax_min_coins`, `danger_dist`, `flee_dist`, `pay_tol`, `pay_giveup`, `coin_timeout`, `sprint_min_dist`, `sprint_min_stamina`, `tree_prio`, `target_archers/workers/farmers/knights`, веса `w_*`.

## Метрики эпизода (`Bot.Metrics`)
- Экономика: `coins_in`, `coins_spent`, `buys`, `final_purse`.
- Развитие: `buildings`, `buildings_started`, `buildings_completed`, `max_buildings`, `trees_marked`, `trees_chopped`.
- Люди: `citizens`, `recruited_beggars`, `first_archer`, `first_worker`.
- Движение: `distance`, `walk_distance`, `run_distance`.
- Лошадь: `horse_exhaustion`, `horse_rest_time`.
- Ошибки: `failed_coin`, `failed_buy`, `failed_recruit`, `failed_tree`, `unpicked_coins`, `coins_lost`.
- Прочее: `crown_lost`, `crown_picked`, `deaths`, `inactivity_penalty`, `seconds`, `day`, `generation`.

## Очки (`fitness` / `score_episode`)
Формула из `bounties.txt` (ключевые веса):
- `coin_collect = 5`, `coin_spend = 4`, `buy = 2`, `recruit_beggar = 20`.
- `buy_castle_base = 100`, `buy_castle_upgrade = 50`.
- `tree_chop = 5`, `survival = 0.05`.
- `death = -3000`, `crown_lost = -1000`, `idle = -15`.
- `unpicked_coin` (градиент 1–5 за монету), `failure_penalty_ratio = 0.5`.

## Подтверждение действий
- **Найм**: засчитывается только если после броска монеты появился `Peasant (P)`. Иначе `failed_recruit`.
- **Покупка**: засчитывается, если `spent >= price` (монеты реально списаны).
- **Оплата**: бот стоит неподвижно 0.5 с (позиция ±0.05), ждёт кружки, затем жмёт S.
