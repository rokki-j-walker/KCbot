# KCbot — Obsidian Vault

Это хранилище Obsidian с документацией по проекту **KCbot** (бот для Kingdom: Classic + WPF-лаунчер).

## Как открыть
1. Запустите Obsidian.
2. «Open folder as vault» → выберите папку `obsidian` (в корне проекта KCbot).
3. Начните с `00 Индекс.md`.

## Структура
- `00 Индекс.md` — дашборд и навигация.
- `01`–`11` — обзор, архитектура, движки, лаунчер, метрики, сравнение Python↔C#, тесты, журнал, задачи, логи.

## Плагины (опционально)
- **Dataview** — для запросов по задачам/журналу.
- **Mermaid** — диаграммы уже встроены в `02 Архитектура.md`.

## Правило ведения
- Любое изменение фиксируйте в `09 Журнал изменений.md` (дата + что сделано).
- Задачи и баги — в `10 Задачи и известные проблемы.md`.
- При переносе функций Python → C# обновляйте `07 Сравнение Python ↔ C#.md`.
